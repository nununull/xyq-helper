# 175DT 完整分类导航设计

## 目标

按 175DT 官网导航展示全部可查询分类。父分类仅作为分组标题，用户只能选择具体分类。分类数据在构建期同步，运行时不依赖官网分类页面。

## 数据来源

- `npm run sync:categories` 请求 `https://175dt.com/`。
- 同步脚本解析官网导航并生成 `src/data/activityCategories.ts`。
- 生成结果保留在仓库中；网络失败时不覆盖上次成功数据。
- 当前分组为：副本、科举、日常活动、节日活动、口袋版、其他、更多。
- 父分类 ID 不写入可选列表；同名不同 ID 的具体分类分别保留。

## 界面

- 左侧分类栏默认展示全部分组和具体分类。
- 分组标题不可点击，显示当前可见分类数量。
- 分类区独立滚动，不拉长主工作区。
- 提供名称搜索，搜索后移除空分组。
- 当前分类沿用现有高亮、持久化和切换生命周期。

## 失败处理

- 官网请求失败、导航缺失、结果为空或 ID 重复时同步命令失败。
- 失败发生在写文件前，仓库中的旧静态清单保持不变。
- 前端运行时不发起分类同步请求。

## 验收

- 当前官网数据生成 7 个分组、53 个唯一可查询分类。
- “副本”等父分类不能被选择。
- 分类搜索能按具体名称过滤并移除空分组。
- 切换具体分类继续使用对应 ID 查询远程题库。
- 全套测试、生产构建和浏览器布局验收通过。
