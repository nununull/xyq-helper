# 共享预览校准流程设计

## 1. 目标

将首次使用和重新校准统一为一条连续流程：选择活动分类、授权共享游戏窗口、在共享画面预览中框选题干与选项、保存区域并开始连续识别。保留现有纯前端 OCR、IndexedDB 缓存和远程查询链路。

## 2. 用户流程

### 首次使用

1. 页面展示活动分类和“连接游戏画面”按钮。
2. 用户选择活动分类后点击连接按钮，浏览器通过 `getDisplayMedia` 请求共享授权。
3. 授权成功后页面展示共享视频预览，不自动开始 OCR。
4. 用户依次在预览内框选题干区域和选项区域。
5. 页面保存以共享视频原始尺寸为基准的区域坐标，并进入连续识别。

### 后续使用

1. 已有有效区域配置时，选择分类并连接游戏画面。
2. 授权成功后直接开始连续识别。
3. 用户可点击“重新校准”，暂停识别但保留共享流，在当前预览内重新框选。
4. 停止按钮同时停止识别与共享流。

## 3. 坐标模型

- 框选组件只在共享视频预览上工作，不再覆盖整个浏览器视口。
- 鼠标坐标先相对预览容器计算，再按照 `videoWidth / renderedWidth` 和 `videoHeight / renderedHeight` 换算为共享视频原始像素坐标。
- 捕获裁剪直接使用原始视频像素坐标，不再乘浏览器 `devicePixelRatio`。
- 旧版区域配置没有可靠的坐标空间标记，升级后视为需要重新校准，不能静默复用。

## 4. 组件边界

### `useScreenCapture`

- 负责请求和释放共享流。
- 向界面提供当前共享流、视频原始尺寸和帧捕获能力。
- 共享轨道由用户主动结束时通知订阅者。

### `CaptureCalibration`

- 渲染实时共享视频预览。
- 管理题干、选项两个框选步骤。
- 输出原始视频坐标系中的两个区域，不负责持久化或启动识别。

### `Dashboard`

- 统一编排分类选择、连接、校准、开始识别、重新校准和停止。
- 授权成功且区域有效时启动识别；缺少有效区域时进入校准。
- 页面隐藏时只取消界面相关的临时交互，不停止共享或识别。
- 切换分类仍停止当前识别和共享，避免旧分类请求污染新分类。

### `SetupWizard`

- 不再作为应用入口阻挡用户。
- 首次连接后的校准能力迁移到主控制台，旧组件删除。

## 5. 状态与反馈

捕获状态继续使用 `idle`、`requesting`、`active`、`paused`、`error`，另由 Dashboard 派生界面步骤：

- 未选择分类：提示“请先选择活动分类”。
- 未连接：显示“连接游戏画面”。
- 请求授权：显示“正在等待共享授权”。
- 已连接但未校准：显示当前框选步骤。
- 已连接且已校准：显示识别阶段和“重新校准”。
- 授权拒绝、无共享源、轨道结束：展示明确中文错误并允许重试。

按钮禁用时必须同时显示原因，不能只通过灰色状态表达。

## 6. 生命周期

- 页面切换到后台、用户切换到游戏窗口时，共享流和识别循环继续运行。
- 用户点击停止、切换分类、共享轨道结束或组件卸载时，停止识别并释放共享流。
- 进入重新校准时停止识别并清空旧题上下文，但保留共享流。
- 校准取消时：若已有有效区域则恢复识别；首次校准则保持已连接等待校准。

## 7. 兼容与迁移

- 配置增加捕获区域坐标版本 `regionCoordinateSpace: 'video-pixel-v1' | null`。
- 只有两个区域均存在且坐标版本为 `video-pixel-v1` 才视为已校准。
- 旧配置合并后坐标版本为 `null`，首次连接必须重新校准。
- 不修改爬虫、题库数据或远程查询协议。

## 8. 测试与验收

### 单元测试

- 预览坐标正确换算为视频原始像素坐标。
- 旧配置升级后要求重新校准。
- 新区域保存时写入坐标版本且不共享响应式引用。
- 页面隐藏不再触发停止捕获。
- 重新校准暂停识别但保留共享流。
- 校准完成后自动启动连续识别。

### 浏览器验收

- 使用 `http://localhost` 打开页面，选择分类后能看到共享授权窗口。
- 共享游戏窗口后能在页面看到实时预览。
- 框选题干和选项后预览截图与实际区域一致。
- 切换到游戏窗口后共享不会自动结束。
- 返回页面可看到持续更新的识别结果。
- 重新校准和停止后状态、按钮及错误反馈一致。

## 9. 实施约束

- 保持 Vue 3、TypeScript、Pinia、Tesseract.js 和 `idb` 技术栈。
- 所有新增或修改的方法必须有中文职责注释。
- 不为兼容单元测试增加无意义的运行时分支。
- 不修改 `crawler/`、`data/` 及用户当前未提交的无关改动。
