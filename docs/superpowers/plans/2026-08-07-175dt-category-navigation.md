# 175DT 完整分类导航实施计划

**Goal:** 构建可同步、可搜索、按官网分组的完整分类选择器。

**Architecture:** Node 脚本解析官网导航并生成静态 TypeScript 数据；纯函数处理分类搜索；Vue 组件只负责分组呈现和选择事件。

- [x] 为官网导航解析、分类完整性和搜索行为编写失败测试。
- [x] 实现 `sync:categories`，校验空结果与重复 ID 后原子更新静态清单。
- [x] 从官网同步 7 组 53 个具体分类。
- [x] 实现独立滚动、默认全展开、支持搜索的分组分类选择器。
- [x] 运行全套测试、生产构建、diff 检查和浏览器验收。
